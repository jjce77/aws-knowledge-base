# Amazon EC2

> Servidores virtuales en la nube de AWS, con capacidad ajustable.

Revisado: 2026-11-05

## Qué es Amazon EC2?

Amazon Elastic Compute Cloud (EC2) ofrece servidores virtuales llamados **instancias**. Eliges procesador, memoria, almacenamiento, red, sistema operativo y modelo de compra. Hay más de 1000 tipos de instancia y un SLA de 99,99 % por región.

## Conceptos clave

| Concepto | Qué es |
|---|---|
| Instancia | Servidor virtual; su tipo define el hardware. |
| AMI | Plantilla con el sistema operativo y el software del servidor. |
| Tipo de instancia | Combinación de CPU, memoria, almacenamiento y red. Familias: uso general, cómputo, memoria, almacenamiento y cómputo acelerado. |
| Par de claves | Clave pública en AWS y clave privada que guardas tú, para acceder. |
| EBS | Volúmenes persistentes de bloques. El almacén de instancia es temporal. |
| Grupo de seguridad | Firewall virtual: qué puertos, protocolos e IP pueden conectarse. |
| IP elástica | IP estática que puedes reasignar a otra instancia. |
| Zona de disponibilidad | Centro de datos aislado dentro de una región; usar varias da resiliencia. |
| Modelo de compra | Bajo demanda (pago por segundo), Spot (capacidad sobrante con descuento) y Savings Plans (compromiso de uso). |

## Servicios relacionados

- **EBS / EFS**: almacenamiento de bloques persistente y de archivos compartido.
- **VPC**: red privada donde se ejecutan las instancias.
- **IAM**: permisos y roles para las instancias y para quienes las administran.
- **S3**: almacenamiento de archivos y respaldos que usan las aplicaciones.
- **RDS**: base de datos administrada para la aplicación.
- **Route 53**: DNS para apuntar tu dominio a la instancia o al balanceador.
- **CloudFront**: red de entrega de contenido para acelerar el acceso.
- **Elastic Load Balancing**: reparte el tráfico entre varias instancias.
- **CloudWatch**: monitoreo de instancias y volúmenes.
- **Systems Manager**: administración de instancias a escala.
- **AWS Backup**: copias de seguridad de instancias y volúmenes EBS.
- **GuardDuty**: detecta uso no autorizado o malicioso.
- **Lightsail**: alternativa más simple, con precio fijo.
- **ECS / EKS**: alternativas para ejecutar contenedores.
- **Lambda**: alternativa sin servidores que administrar.

## Ventajas

- Elasticidad: escala la capacidad en minutos y reduce cuando baja el uso.
- Variedad: procesadores Intel, AMD y Graviton (ARM), GPU, etc.
- Control total: decides sistema operativo, red, almacenamiento y software.
- Alta disponibilidad: zonas de disponibilidad aisladas y SLA de 99,99 %.
- Costos flexibles: facturación por segundo, instancias Spot y Savings Plans.

## Desventajas

- Tú administras el servidor: parches, configuración del sistema operativo y seguridad del software son tu responsabilidad.
- Costos si no se vigila: una instancia encendida o sobredimensionada sigue cobrando y los precios tienen muchas variables.
- Curva de aprendizaje: exige entender un nuevo ecosistema.
- Alta disponibilidad no automática: requiere configurar Auto Scaling y un balanceador.
- Interrumpciones masivas: AWS puede tener fallas generales que afectan a todos los clientes.
- Más operación que alternativas administradas: Lightsail, contenedores o serverless reducen el trabajo.
