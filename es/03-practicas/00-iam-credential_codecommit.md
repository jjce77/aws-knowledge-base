# Crear credenciales de codecommit

## 1. Abrir IAM servicio IAM y entra a Users.

1. Selecciona demo-user-aws.
2. Abre la pestaña Credenciales de seguridad (Security credentials).
3. Baja hasta la sección Credenciales Git HTTPS para AWS CodeCommit (HTTPS Git credentials for AWS CodeCommit).
4. Pulsa Generate credentials.

## 2. Guardar las credenciales

AWS muestra un nombre de usuario y una contraseña de Git. Son distintos a los de inicio de sesión en la consola.

Pulsa Download credentials y guarda el archivo .csv en un lugar seguro.
Si prefieres, copia el usuario y la contraseña directamente.

>Nota: La contraseña solo se muestra una vez. Si la pierdes, debes restablecerla o generar un nuevo par desde esta misma sección. Cada usuario puede tener hasta dos pares de credenciales Git.
